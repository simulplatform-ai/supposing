# Security policy

## Reporting a vulnerability

Please report security problems privately to **security@supposing.app**, not in a public issue. Include what you
found, how to reproduce it, and the version (`supposing --version`). We reply within three working days and tell you
when a fix is released. Our full policy: https://supposing.app/support#security.

This repository is the open-source `supposing` engine, CLI and MCP server. Problems in the hosted service
(app.supposing.app, api.supposing.app) go to the same address.

## Supported versions

Fixes go into the latest release on PyPI. Upgrade with `uv tool upgrade supposing` or `uv add supposing --upgrade`.
